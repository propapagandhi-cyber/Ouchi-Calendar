# おうちカレンダー かんたんガイド

ホーム画面の **「おうちカレンダー」**（オレンジのおうちのアイコン）をタップして開きます。

---

## 見る

- いちばん下のボタンで見かたを変えます：**月**・**週**・**日**・**やること**
- **月**：日にちをタップすると、その日の予定が下に出ます。
- **日**：ママ・長男・次男の予定が、横にならんで出ます。
- 上の **［みんな］［ママ］［長男］［次男］** で、だれの予定を出すか選べます。（ふだんは［みんな］）
- **‹ ›** で前・次へ。画面を左右に指ですべらせても動きます。**［今日］** で今日にもどります。
- 色：ママ＝ピンク、長男＝青、次男＝緑、みんな＝オレンジ。日曜・祝日は赤い字です。

## 予定を入れる

1. 右下の **［＋ 予定］** をタップ
2. **だれの予定？** … 名前をタップ（何人でも。全員なら［みんな］）
3. **なにをする？** … 文字を入れる
   - 下の「よく使う予定」をタップすると、前と同じ時間・人で入ります
4. **いつ？** … 日にちと時間をえらぶ（時間を決めないときは「終日」をオン）
5. **［保存する］**

## 毎週の予定（くりかえし）

入れるときに **くりかえし** で **［毎週］** などをえらび、曜日をタップします。
- 祝日に休みになるなら **「祝日はお休み」** をオン
- 夏休み・冬休みなど、まとめて休むときは **「お休み期間を追加」**

## 「この日だけ休み」にする

1. 予定をタップ
2. **［この日はお休みにする］** をタップ

まちがえたら、すぐ下に出る **［元に戻す］** をタップ。

## 変える・消す

予定をタップ → **［変更する］** または **［削除する］**
毎週の予定のときは「この日だけ」「この日から先すべて」「すべて」からえらびます。
（例：4月から時間が変わる → 4月の最初の日で「この日から先すべて」）

## やること

1. 下の **［やること］** → 右下の **［＋ やること］**
2. だれの？・やること・いつまで？ を入れて **［保存する］**
3. おわったら左の **□** をタップ（✓ になります）

期限のあるやることは、カレンダーのその日にも出ます。

## こまったとき

- **画面を閉じたいとき**：スマホの「もどる」でOK（アプリは閉じません）
- **字が小さい**：右上 **⚙ 設定** → 文字の大きさ →「大きい」「とても大きい」
- **上に黄色いお知らせが出た**：「インターネットにつながっていません」なら、そのまま使ってOK（あとで自動で送ります）。それ以外のお知らせは、パパに見せてください。
