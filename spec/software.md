# ソフトウェア仕様（WHAT ＋ HOW）

> **これは1枚版。** 肥大化したら同名フォルダ `software/` に昇格する（参照パスとロジックは変えない）。
> データ形式と同期の約束は `interface/data-schema.md` に分離している。

## アーキテクチャ概要

ブラウザだけで動く単一ページの PWA。サーバーは持たない。起動時は端末内（localStorage）のデータで即描画し、
接続コードが設定されていれば裏で GitHub のデータ用リポジトリと同期する。同期は「取得 → レコード単位マージ → 書き込み（sha で楽観ロック）」。

### レイヤ構成

```
UI 層      ui/views.js（月・週・日・やること） ui/editor.js（詳細・入力シート） ui/settings.js  ui/dom.js（h・シート・トースト）
   │        main.js（画面状態 state・操作 → データ更新 → 再描画）
ロジック層  recurrence.js（くりかえし展開） holidays.js（祝日） dateutil.js（日付） model.js（スキーマ・マージ）
   │
保存層      store/local.js（localStorage） store/sync.js（同期エンジン＋スケジューラ） store/github.js（Contents API クライアント）
```

### モジュール責務

| モジュール | 責務 | 対応仕様 |
|---|---|---|
| `config.js` | 設定値（下表）を1か所に集約 | §設定値 |
| `dateutil.js` | `YYYY-MM-DD` 文字列での日付計算・表示整形 | — |
| `holidays.js` | 日本の祝日（振替休日・国民の休日を含む）の計算 | R-9 |
| `recurrence.js` | 予定を期間内の「回」に展開。例外（お休み・変更）を適用 | R-4, R-5, R-24 |
| `model.js` | 空データ生成・正規化（移行）・マージ・ID 発行 | R-14, data-schema |
| `store/local.js` | 端末内保存（データ・同期メタ・接続設定・表示設定） | R-12, R-13 |
| `store/github.js` | GitHub Contents API の取得・書き込み、エラー分類 | R-7 |
| `store/sync.js` | 同期エンジン（競合時リトライ）と実行タイミング管理 | R-7, R-13, R-14 |
| `ui/*.js`, `main.js` | 画面描画・操作 | R-1〜R-3, R-6, R-8, R-10, R-11, R-20〜R-25 |
| `sw.js` | オフライン用キャッシュ（ネットワーク優先・失敗時キャッシュ） | R-13 |

### 起動シーケンス

1. `config.js` を読み込み、表示設定（文字サイズ・週のはじまり・最後の表示）を localStorage から復元。
2. localStorage のデータを `normalize()` して即描画（なければ初期メンバー入りの空データ）。
3. Service Worker を登録。
4. 接続コードがあれば同期を開始（起動時・編集の 1.5 秒後・アプリが前面に戻った時・オンライン復帰時・前面表示中は 2 分ごと）。

| 週のはじまり（既定） | 日曜（設定で月曜に変更可・端末ごと） |

## 画面（R-10・R-11 を満たすこと）

```
┌────────────────────────────┐
│ ‹  2026年11月  ›   [今日] ⚙設定 │ ← 上部バー（期間移動・今日へ・設定）
│ [みんな][ママ][長男][次男]       │ ← だれを表示するか（1つ選ぶ）
├────────────────────────────┤
│                            │
│   月／週／日／やること の本体    │ ← 左右スワイプでも期間移動
│                     [＋ 予定] │ ← 追加ボタン（ラベル付き）
├────────────────────────────┤
│  📅月   🗓週   📄日   ✅やること │ ← 下部タブ（アイコン＋文字）
└────────────────────────────┘
```

- **月**：7列のマス。予定は色付きの短い帯（名前の色）で最大3件。日をタップするとその日が選択され、**マスの下にその日の予定一覧**が出る。
- **週**：1日1行の縦並び。各行に時刻・タイトル・だれのタグ。空いている行をタップでその日に追加。
- **日**：メンバーごとの列（絞り込み中はその人だけの1列）。終日→時刻順にカード表示。下にその日が期限のやること。
- **やること**：メンバーごと（絞り込み時はその人）にチェックリスト。期限切れは赤、今日は橙。済んだものは「おわったこと」に畳む。
- **予定の詳細シート**：タイトル・日時・だれ・くりかえし説明・メモ。ボタン：「この日はお休み」（くりかえしのみ）「変更する」「削除する」「閉じる」。
- **入力シート**：だれ（色ボタン・複数可・「みんな」で全員）→ なに（入力＋よく使う予定ボタン）→ いつ（日付・終日・開始/終了・複数日）→ くりかえし → メモ → 「保存する」。
- **設定シート**：文字の大きさ・週のはじまり・メンバー（名前・色・追加・削除）・同期（接続コード）・バックアップ・バージョン。
- 同期に問題があるときだけ、上部バーの下に**文字で**お知らせを出す（例：「インターネットにつながっていません。つながったら自動で送ります」）。

## 振る舞い（behaviors）

### B-1 予定の登録・表示（月・週・日・絞り込み）

- **satisfies**: R-1, R-2, R-3, R-11, R-20, R-21, R-24
- **モジュール**: `ui/views.js`, `ui/editor.js`, `recurrence.js`
- **シーケンス**: 「＋ 予定」→ 入力シート（日付は選択中の日、だれは絞り込み中の人／みんな表示なら空）→「保存する」→ 端末に保存 → 再描画 →「保存しました」トースト → 同期予約。
- **エラー処理**: タイトル空・だれ未選択は保存せず、該当欄の下に赤字で案内。終了時刻が開始以前なら開始＋60分に直す。
- **Acceptance**:
  1. 長男・次男の2人を選んだ予定は、日表示で長男・次男の両方の列に出る。全員を選ぶと「みんな」タグ（オレンジ）で出る。
  2. 絞り込みで「長男」を選ぶと、長男を含む予定だけが月・週・日・やることに出る。
  3. 月表示で日をタップすると、その日の予定一覧が時刻順（終日が先頭）で下に出る。
  4. よく使う予定ボタンをタップすると、タイトル・時刻・だれが前回の同名予定と同じ値で入る。
  5. 複数日の予定（11/20〜11/22）は3日すべてに表示され、初日は開始時刻、最終日は終了時刻が付く。

### B-2 くりかえしと例外

- **satisfies**: R-4, R-5, R-22
- **モジュール**: `recurrence.js`, `ui/editor.js`
- **くりかえし規則**:
  - 毎日：開始日から毎日。
  - 毎週：選んだ曜日（複数可）。2週ごと：月曜始まりの週で数え、開始日の週から1週おき（土日をまとめて隔週にできる）。
  - 毎月：開始日と同じ日付（その日がない月は無し）、または「第n◯曜日」（開始日が月の最終週の第5週なら「最終◯曜日」）。
  - 毎年：開始日と同じ月日。
  - 終わり：「ずっと」または指定日まで（その日を含む）。
- **例外の優先順**: お休みの日／お休み期間／祝日はお休み → その回は出ない。それ以外で「この日だけ変更」があれば、その内容で上書きして出す。
- **詳細シートからの操作**:
  - 「この日はお休み」：その日をお休みの日に追加 → 「お休みにしました［元に戻す］」。
  - 「変更する」→「この日だけ」「この日以降すべて」「すべて」を選ぶ。
    - この日だけ：日付を変えなければ上書き（override）。日付を変えたら、元の日をお休みにして単発の予定を新規作成。
    - この日以降すべて：元の予定の終わりを前日にし、その日から始まる新しいくりかえし予定を作る（以降のお休み・変更は新しい側へ移す）。その日が初回なら「すべて」と同じ。
    - すべて：くりかえし予定そのものを編集。入力シートに「お休みにした日」一覧（［戻す］付き）と「お休み期間」（追加・削除）が出る。
  - 「削除する」→「この日だけ」（＝お休み）「この日以降すべて」（終わりを前日に）「すべて」を選ぶ。いずれも「元に戻す」可。
- **Acceptance**（`impl/tests/recurrence.test.mjs`）:
  1. 毎週土曜（開始 2026-11-07）を 2026-11 で展開すると 7, 14, 21, 28 日。
  2. 上の予定に 11/21 をお休みにすると 7, 14, 28 日。
  3. 「祝日はお休み」の毎週月曜は、2026-09-21（敬老の日）に出ない。
  4. お休み期間 2026-12-24〜2027-01-07 の毎週水曜は、その間に出ない。
  5. 11/14 だけ 13:00〜15:00 に変更すると、その回だけ時刻が変わり、他の回は元の時刻。
  6. 2週ごと土日（開始 2026-11-07 土）は 11/7, 11/8, 11/21, 11/22 … と出る。
  7. 毎月 第2土曜（開始 2026-11-14）は 2026-12-12, 2027-01-09 に出る。毎月31日は 11月に出ない。
  8. 終わり 2026-11-20 の毎日予定は 11/21 以降に出ない。

### B-3 やること

- **satisfies**: R-8
- **モジュール**: `ui/views.js`, `ui/editor.js`
- **シーケンス**: やることタブの「＋ やること」→ なに・だれ（1人）・期限（なし／今日／明日／日付）→「保存する」。チェックで完了（もう一度で戻す）。
- **Acceptance**:
  1. 期限付きのやることは、月表示の選択日一覧と日表示の下に「□ タイトル」で出る。
  2. 期限切れは赤字「◯/◯まで（すぎています）」、今日が期限は橙。
  3. 完了したものは「おわったこと（n）」に畳まれ、開くと見られる。個別に削除できる。

### B-4 同期（GitHub 非公開リポジトリ）

- **satisfies**: R-7, R-13, R-14, R-15
- **モジュール**: `store/github.js`, `store/sync.js`, `ui/settings.js`
- **シーケンス**: `interface/data-schema.md` §同期 のとおり。
- **エラー処理**: オフライン → 「つながったら自動で送ります」。401/403 → 「接続できません。設定の接続コードを確認してください」。競合（409/422）→ 取得し直してマージ、最大3回。
- **Acceptance**（`impl/tests/sync.test.mjs`、Mock クライアント）:
  1. リモートにファイルが無ければ、端末のデータで新規作成する。
  2. 端末とリモートで別々の予定を追加していたら、同期後は両方が残る（リモートにも書き込まれる）。
  3. 同じ予定を両方で変更していたら、`updatedAt` が新しい方が残る。
  4. 書き込みで競合（sha 不一致）が1回起きても、取得し直して2回目で成功する。
  5. リモートと内容が同じなら書き込みをしない。

### B-5 戻るボタン・PWA

- **satisfies**: R-6, R-10, R-12, R-13
- **モジュール**: `ui/dom.js`, `sw.js`, `manifest.webmanifest`
- **振る舞い**: シートを開くたびに履歴を1つ積み、Android の「戻る」で一番上のシートだけ閉じる（アプリは閉じない）。
  ホーム画面に追加すると全画面（standalone）で起動。オフラインでもキャッシュから起動する。
- **Acceptance**:
  1. 詳細シート →「戻る」でシートだけ閉じ、カレンダーが残る。
  2. 機内モードでも起動して予定が見え、追加もでき、通信復帰後に同期される。

## 祝日（R-9）

`holidays.js` で計算する（外部 API に依存しない）。対象：元日、成人の日（1月第2月曜）、建国記念の日、天皇誕生日（2/23）、春分の日・秋分の日（近似式、1980〜2099年有効）、昭和の日、憲法記念日、みどりの日、こどもの日、海の日（7月第3月曜）、山の日（8/11）、敬老の日（9月第3月曜）、スポーツの日（10月第2月曜）、文化の日、勤労感謝の日、振替休日、国民の休日（祝日に挟まれた平日）。2020・2021年の五輪特例も含む。
法改正で祝日が変わったら本節と `holidays.js` を更新する。
