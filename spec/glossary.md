# 用語集

正規語を1つに固定し、コード・仕様・UI で表記を揃える（SSOT の一部）。

| 正規語（UI） | 略語 | English（コード） | 定義 |
|---|---|---|---|
| メンバー | — | member | 予定・やることの持ち主。初期値はママ・長男・次男。名前と色を持つ |
| みんな | — | all members | 全メンバーが対象の予定、または絞り込みなし（全員表示）の状態 |
| 予定 | — | event | 日付（＋時刻）を持つ出来事。くりかえし設定を持てる |
| くりかえし | — | repeat | 予定が定期的に発生する規則（毎日・毎週・2週ごと・毎月・毎年） |
| 回 | — | occurrence | くりかえし予定を展開した、ある1日分の予定 |
| お休み（この日はお休み） | — | skip date | くりかえし予定のある1回だけを発生させない例外 |
| お休み期間 | — | skip range | くりかえし予定を期間でまとめて発生させない例外（夏休みなど） |
| 祝日はお休み | — | skipHolidays | 祝日に当たる回を自動でお休みにする設定 |
| この日だけ変更 | — | override | くりかえし予定のある1回だけ時刻・内容を変える例外 |
| やること | — | task | 期限（任意）とチェック（完了）を持つ ToDo |
| 接続コード | — | connection code | GitHub のデータ用リポジトリへ接続する設定（所有者・リポジトリ名・トークン）を1つの文字列にまとめたもの |
| 同期 | — | sync | 端末内のデータと GitHub 上の `data.json` をマージして揃えること |
| データ用リポジトリ | — | data repo | 予定データ `data.json` を置く GitHub 非公開リポジトリ（`Ouchi-Calendar-data`） |
| シート | — | sheet | 画面下からせり上がる入力・詳細の画面。Android の「戻る」で閉じる |
